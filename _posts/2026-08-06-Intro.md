Today I started learning how unix-based systems work.

First step was to install vim and nanoand sudo in order to change hostname. 
I changed hostname via 
```
sudo vim /etc/wsl.conf
```
I added next lines
```
[network]
hostname = arch
generateHosts = false
```

Also, in order to change root password in wsl you can use
In cmd
```
wsl -u root -d archlinux  
```
Then type new password
```
passwd root
```
